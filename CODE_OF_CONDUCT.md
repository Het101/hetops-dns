# Code of conduct

## Our pledge

We want HetOps DNS to be a project people are glad they contributed to. Everyone taking part — maintainers, contributors, people reporting a wrong result at 2am during an outage — deserves a harassment-free experience, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

Things that make this project work:

- Assuming the person on the other end is competent and short on time
- Giving and taking feedback on the code rather than the person
- Saying "I was wrong" early and without ceremony
- Remembering that someone filing a confused bug report is usually mid-incident

Things that will not be tolerated:

- Sexualised language or imagery, or unwelcome sexual attention
- Trolling, insults, derogatory comments, and personal or political attacks
- Public or private harassment
- Publishing someone's private information without explicit permission
- Pressuring anyone to share credentials, API keys, or private DMARC report data in an issue or PR

That last one is specific to this project and it is not negotiable. If you need data to reproduce a bug, ask for a scan of a public domain or a synthetic report.

## Enforcement

Report unacceptable behaviour to the maintainers through [GitHub's private reporting](https://github.com/Het101/hetops-dns/security/advisories/new) or by email to patel.x.het@gmail.com. Reports are handled confidentially.

Maintainers will remove, edit, or reject contributions that do not align with this code of conduct, and will explain moderation decisions when asked. Maintainers who do not follow it in good faith may face consequences decided by the project's other maintainers.

### Scale of response

1. **Correction** — a private note explaining what was wrong and why.
2. **Warning** — consequences stated for continued behaviour, with a period of no interaction with those involved.
3. **Temporary ban** — from any interaction with the project for a set period.
4. **Permanent ban.**
